WHY WILLNEW

팀이 맡기고, 검증된 결과를 받는 흐름.

여러 에이전트를 실행하는 작업 공간에 팀 요청, 자동 검증, 사람의 검토와 승인을 연결했습니다. 시간·비용·변경 크기를 근거로 결과를 추천하고, 최종 병합은 사람이 결정합니다.

  1. 01 / 요청 · 계획

    팀의 일을 맡기기

    채널의 @willnew 또는 빠른 요청 창에서 버그 수정, 테스트 작성, 문서화 등을 맡깁니다.

  2. 02 / 실행 · 비교

    격리된 공간에서 실행

    Claude Code와 Codex가 각각 작업합니다. 터미널·변경·미리보기와 시간·비용을 함께 확인합니다.

  3. 03 / 검증 · 수정

    실패 로그로 다시 수정

    검증 명령의 종료 코드로 판정합니다. 실패 로그를 되돌려 한 번 더 수정하고, 통과한 결과를 승인 대상으로 올립니다.

  4. 04 / 검토 · 승인

    사람이 최종 결정

    줄 댓글과 병합 전 확인으로 결과를 검토합니다. 승인하면 병합하고, 반려하면 이유를 기록합니다.
